
# Testing Guide

## Short Test

1. Run `Sleep — Start`.
2. Wait approximately five minutes.
3. Run `Sleep — Finish`.
4. Enter `0` minutes for sleep latency.
5. Open Apple Health.
6. Navigate to Sleep and inspect the new records.

Expected results:

- One `In Bed` record
- One `Asleep` record
- Shortcuts listed as the data source

Delete the short test records afterward so they do not affect
sleep statistics.
