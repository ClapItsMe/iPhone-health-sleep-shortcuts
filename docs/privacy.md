
# Privacy

This project is designed to operate locally within Apple's ecosystem.

## Data Stored

The workflow stores:

- A temporary marker file in iCloud Drive
- Sleep interval records in Apple Health

## Data Not Collected

The project does not collect or transmit:

- Names
- Email addresses
- Apple IDs
- Location
- Advertising identifiers
- Analytics
- Health data to external servers

## User Control

Users can inspect every Shortcut action before installation and can
remove Health permissions at any time through Apple Health settings.

## Medical Disclaimer

This project is intended for personal sleep logging only.

It is not a medical device and should not be used to diagnose, monitor,
prevent, or treat any medical condition.
