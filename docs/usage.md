
# Usage Guide

## Starting a Session

When ready to sleep:

1. Tap `Sleep — Start`.
2. Confirm that Sleep Focus turns on.
3. Confirm that the start notification appears.

## Finishing a Session

When getting out of bed:

1. Tap `Sleep — Finish`.
2. Enter estimated sleep latency in minutes.
3. Confirm that the session was saved.
4. Check Apple Health if necessary.

Do not run `Sleep — Start` more than once during the same session,
because it will reset the recorded starting time.
