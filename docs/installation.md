
# Installation Guide

## 1. Download the Shortcuts

Download both files from the `shortcuts` directory:

- `Sleep-Start.shortcut`
- `Sleep-Finish.shortcut`

Open each file on the iPhone and review every action before adding it.

## 2. Create the iCloud Folder

In the Files app, create:

iCloud Drive/Shortcuts/SleepTracker

## 3. Verify File Paths

Both shortcuts must use:

SleepTracker/sleep-start.txt

## 4. Grant Permissions

When prompted, allow the shortcuts to:

- Access the selected iCloud Drive folder
- Write Sleep information to Apple Health
- Control Sleep Focus

## 5. Configure Sleep Focus

Keep Sleep Schedule enabled if you use Apple's Sleep | Wake Up alarm.

Disable:

Use Schedule for Sleep Focus

The shortcuts should control Sleep Focus manually.

## 6. Add Home Screen Icons

Add `Sleep — Start` and `Sleep — Finish` to the Home Screen.

The custom icons are available under:

assets/icons/
